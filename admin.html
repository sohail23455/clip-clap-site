What the numbers mean

Estimated unique visitors are daily browser sessions. No fingerprinting or cross-day identity. The selected range sums those daily estimates; the same person can appear more than once.

Unique installs are consenting installations first observed since analytics began. Active Today uses the current UTC day; Active 7 and 30 Days use rolling windows. These cards, latest-version users and version distribution stay independent of the date filter. Version records expire after 395 days without any events.

Daily installer downloads show increases between GitHub snapshots, collected daily and on dashboard refresh. The first snapshot is a baseline; gaps cannot identify the actual download day. Clicks are shown separately. Adoption history covers the last 395 days.

App events contain only a random installation ID, approved event name, version, operating-system family and time. No videos, transcripts, API keys, filenames or personal content.
