PRIVACY

Your work stays yours.

Optional app analytics

Off by default. If you enable anonymous usage analytics in Settings → Privacy, Clip Clap sends a locally generated random installation ID, app version, an approved event name, Windows OS family and time. Events measure installations, app opens and closes, version changes, clip creation, completed exports and update checks. No videos, filenames, transcripts, project names, file paths, API keys, email addresses, hardware identifiers or personal content are included. This random ID is not a fingerprint.

Turn the switch off to stop sending new events and clear the pending queue. Previously sent anonymous counts remain. The ID survives normal upgrades and is reset when you remove the app's saved data. Uninstalling normally preserves your projects and settings. While offline, at most 100 anonymous events are queued for up to 7 days.

Website counts

We count page visits and download clicks using a random identifier held in session storage, rotated each UTC day. We do not use tracking cookies, fingerprinting, advertising services, full URLs or referrers. Estimated visitors mean daily browser sessions, not identified people. Do Not Track and Global Privacy Control are respected. Counting failures never block downloads.

Storage and access

Only the owner can view analytics. Raw events are deleted after 90 days. Website session identifiers expire after 31 days; inactive installation records and daily version records expire after 395 days. Anonymous historical totals contain no identifiers. Short-lived keyed request hashes expire after two minutes for abuse prevention; raw IP addresses are not stored in analytics.

HTTPS hosting and database providers necessarily handle network addresses while serving requests and may keep their own operational security logs. Those are separate from Clip Clap analytics. Owner login uses an email address only for authentication, never as an app or visitor analytics field.

Media and cloud AI

Video processing stays on your device. Optional cloud AI actions send only the content you approve to your chosen provider. Provider keys and content never enter the analytics system.
