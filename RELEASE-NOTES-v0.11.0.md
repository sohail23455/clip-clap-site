# Clip Clap v0.11.0

Release date: 2026-10-05 · Windows 10/11

- Auto Improve: more restrained, content-aware editing, with a bounded quality check that keeps the last verified render when a correction does not help.
- Overlay Cleanup: select your own overlay or use automatic detection. Small marks on simple backgrounds can be reconstructed locally; uncertain areas retain the original for review. Blur remains an explicit choice.
- Consistent blue-to-purple C/play branding across the Windows app, installer, website and favicon.
- Connect AI supports compatible services through the Universal Connector, including verified APMix ranking, metadata and review. Local AI remains available without a paid API key.
- Reliable exports and update preparation, preserving projects, models and encrypted connections across installation.
- Cleaner Auto controls, Results and area selection, plus corrected setup privacy information and About labels.

Original media stays untouched. Full video files are never sent to cloud AI; optional cloud actions require your approval for the selected text or audio. Review captions and creative decisions before sharing. Overlay reconstruction is intentionally conservative.

This Windows evaluation installer is unsigned and includes LGPL-compatible FFmpeg.
